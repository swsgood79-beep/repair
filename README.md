# 한결전파사

할아버지가 남긴 골목 전파사를 물려받아, 14일 안에 빚 60만원을 갚고 가게를 본점까지 키우는 수리 추리 게임입니다.
가게가 커질수록 고칠 수 있는 전자제품이 늘어납니다.
TypeScript + Vite + Canvas. 640×360 도트 화면 위에 고해상도 글자 레이어를 겹쳐 그립니다.
서버 없이 정적 호스팅으로 돌아가고, 저장은 브라우저 localStorage에 합니다. 가로 화면에 맞춰 크기가 조절됩니다.

## 가게 키우기

| 단계 | 이름 | 비용 | 새로 고칠 수 있는 물건 |
| --- | --- | --- | --- |
| 1 | 골목 수리점 | 시작 | 탁상 스탠드, 선풍기, 진공관 라디오, 휴대용 카세트, 괘종시계, 전기다리미, 다이얼 전화기 |
| 2 | 작업대 넓히기 | 15만원 | 전기밥솥(지켜봐야 드러나는 설익음), 스테레오 앰프(왼쪽·오른쪽 비교) |
| 3 | 2층 공방 | 30만원 | 턴테이블 전축(회전수·울렁임), 재봉틀(힘이 새는 곳, 가마 타이밍) |
| 4 | 한결전파사 본점 | 45만원 | 흑백 TV(화면 증상으로 추리), 전자계산기(표시창과 측정값) |

골목 수리점의 물건은 처음엔 쉬운 고장만 들어오고, 날이 갈수록 어려운 고장이 섞인다. 새로 연 물건도 같은 방식이다.
속도 나사·수직 동기·가마처럼 돌려 맞추는 부품은 "조정 나사 돌리기" 미니게임으로 고친다.

빚을 14일 안에 못 갚으면 가게를 잃는다. 빚을 다 갚고 본점까지 키우면 성공. 단계가 오르면 손님과 선반 칸도 늘고 가게 모습이 바뀐다.

## 화면과 조작 — 방탈출처럼

- **자물쇠 = 고장**: 물건에 걸린 자물쇠 수가 남은 고장 수다. 연쇄 고장이 터지면 하나 늘어난다.
- **반짝이는 곳을 조사**: 공구는 5개. 손(켜기·만지기·흔들기), 드라이버, 눈, 테스터(측정점=전압, 부품=저항), 청진기.
- **단서 획득!**: 조사할 때마다 단서 카드가 내려오고 "통과 / 의심 / 유력!" 도장이 찍힌다. 카드에는 해석까지 적혀 있다.
- **용의자 보드**: 부품 카드에 단서가 자동으로 도장을 찍는다. 정상 측정점 앞은 통과, 끊긴 구간은 의심.
- **범인 지목**: 용의자를 눌러 고칠 방법을 고르면 자물쇠가 딸깍 풀리거나 철컥 거부한다. 틀리면 수리비 10% 감소.
- **수리 손맛 (미니게임)**: 실제 작업 순서를 따라 한다.
  - 덮개: 드라이버로 나사를 반시계로 돌려 푼다. 너무 빨리 돌리면 미끄러진다.
  - 납땜: 인두로 패드를 달구고 초록 온도에서 떼서, 실납을 눌러 봉긋하게 흘린다. 덜 달구면·식으면 냉납, 오래 대면 패드가 타고, 넘치면 다시.
  - 납땜 부품 교체: 다리 납 녹여 흡입기 → 뽑기 → 구멍 맞춰 꽂기 → 다리 두 개 납땜.
  - 전구 돌려 빼고 끼우기, 퓨즈·진공관 뽑고 꽂기, 코드 피복 벗겨 단자에 조이기, 벨트 걸기.
  - 세척(뿌리고 문지르기), 주유(돌아가는 구멍에 맞춰 떨어뜨리기), 다이얼 실 걸기, 시계 박자 맞추기, 휜 톱니 펴기, 바늘 핀 박기.
- **소리**: 음원 파일 없이 Web Audio로 합성한다. 장면마다 다른 배경음악(제목·카운터·작업대·미니게임·결말), 공구·부품 효과음, 문 종·도장·자물쇠·금전등록기·셔터 소리. 메뉴에서 음악과 효과음을 따로 끌 수 있다.
- **할아버지 쪽지**: 막히면 3단계 힌트(방법 → 위치 → 정답). 한 번에 5분.
- **확대**: 부품을 보거나 만지거나 재면 화면이 그 부품 쪽으로 다가간다. [전체 보기]로 돌아온다.
- **실제 작업 순서**: 수리 전에 플러그를 직접 뽑아야 하고, 끝나면 덮개를 다시 덮고 나사를 조여야 돌려줄 수 있다. 새 부품은 서랍에서 헌 부품과 같은 규격을 골라야 한다.
- **카운터**: 손님이 증상을 말하고, 돌려주면 표정과 동전으로 반응한다.

## 무엇이 다른가

고장 단서를 대본으로 보여주지 않습니다. 물건마다 **작은 시뮬레이션**이 있고, 플레이어가 보는 모든 것은 숨은 고장 상태에서 계산됩니다.

- **테스터 전압**: 전원을 넣고 놋쇠 측정 단자에 대면 실제 회로 상태대로 값이 나옵니다. 전압이 사라지는 두 단자 사이에 범인이 있습니다.
- **테스터 저항**: 전원을 빼야 잴 수 있습니다. ∞는 끊김, 0에 가까우면 단락입니다.
- **흔들기 · 지켜보기**: 흔들어야만, 또는 10분 켜 두어야만 드러나는 간헐 고장이 있습니다.
- **귀 · 손 · 눈 · 돋보기**: 쇳소리가 나는 위치, 뜨거운 부품, 뻑뻑한 축, 머리카락 같은 금.
- **신호 주입기**: 라디오 신호 단에 삐 소리를 넣어 뒤쪽 회로를 반으로 잘라 봅니다.
- **연쇄 고장**: 단락된 콘덴서를 두고 퓨즈만 갈면 켜는 순간 다시 끊어집니다. 웅 소리만 내는 선풍기를 켜 두면 온도 퓨즈가 탑니다.
- **수리 결과를 알려주지 않습니다**: 교체·세척·납땜을 해도 고쳐졌는지는 다시 켜 봐야 압니다.
- **잠복 고장**: 손님은 카운터에서 잠깐 켜 보고 가져갑니다. 오래 켜야 드러나는 고장을 남기면 다음 날 무상 재수리로 돌아오고 신뢰가 깎입니다.

| 물건 | 열리는 날 | 고장 | 핵심 |
| --- | --- | --- | --- |

| 진공관 라디오 | 3일 | 8종 | 전원부·신호부, 단락 콘덴서 함정, 열 간헐 냉납, 신호 주입 |
| 휴대용 카세트 | 5일 | 6종 | 전기와 고무·기계가 섞인 고장 |

의뢰마다 고장 1~3개를 무작위로 조합하므로 같은 물건도 매번 다른 퍼즐이 됩니다.

## 돈과 목표

- 하루 09:00~19:00. 측정·분해·수리 모두 게임 시간이 듭니다.
- 교체는 확실하지만 부품값이 들고, 세척·납땜·주유·조정은 싸지만 맞는 고장에만 듣습니다.
- 매일 마감 때 2만원이 나갑니다. 마감일을 넘기면 손님이 그냥 찾아가고 신뢰가 깎입니다.
- 동네 신뢰가 오르면 손님이 늘고 수리비도 오릅니다.
- 공구상: 돋보기(1일차), 신호 주입기(3일차).
- 고장 도감: 처음 고친 고장이 증상과 함께 기록됩니다.

## 실행

```sh
npm install
npm run dev
```

```sh
npm test        # 모든 고장이 구별 가능하고 정답 수리로 풀리는지 검증
npm run balance # 실력별 14일 수익 시뮬레이션
npm run build   # dist/ 와 단일 파일 dist/artifact.html 생성
```

## 구조

```text
src/items/      물건별 부품·측정 단자·고장 정의와 시뮬레이션 (lamp, fan, radio, cassette, clock)
src/game.ts     상태, 의뢰 생성, 공구 사용, 수리, 반환, 하루 흐름, 저장
src/gfx/        도트 그리기 (painter: 캔버스·7세그먼트, parts: 부품·확대 그림·아이콘·손님)
src/ui/         장면 (bench: 작업대·용의자 보드·단서 수첩, mini: 수리 미니게임, clues: 단서 해석, scenes: 제목·카운터·장부·도감, tutorial)
src/audio.ts    배경음악 연주기, 효과음, 물건 소리(험·잡음·방송·똑딱) 합성
tests/check.ts  퍼즐 검증 (구별 가능성, 연쇄 고장, 잠복 고장, 무작위 의뢰 1,400건)
```

새 물건은 `src/items/`에 `ItemDef` 하나를 추가하고 `ITEMS`에 등록하면 됩니다.
`npm test`가 새 고장이 정상품·다른 고장과 구별되는지, 정해진 수리로 풀리는지 자동으로 확인합니다.
